# Pygame Tic-Tac-Toe (Human vs AI)

A sleek, modern desktop implementation of Tic-Tac-Toe built in Python using **Pygame**. Play against an unbeatable AI powered by the **Minimax Algorithm** featuring smooth interactive controls, hover state buttons, and keyboard shortcuts.

---

## Features

- **Unbeatable AI:** Employs the Minimax algorithm to calculate optimal moves in real time.
- **Interactive UI:** Built-in **Restart** and **Exit** buttons with hover feedback.
- **Keyboard Shortcuts:** Quick-access keys for seamless gameplay.
- **Clean Graphics:** Minimalist color scheme and clean visual aesthetics.

---

## Controls

| Action | Control |
| :--- | :--- |
| **Place Symbol** | Left-click on any empty grid square |
| **Restart Game** | Click **Restart** button OR press <kbd>R</kbd> |
| **Exit Game** | Click **Exit** button OR press <kbd>Esc</kbd> |
